## 2. 正确供电方式

### 2.1 遥控器

- 使用套件中的 AAA 电池盒；
- USB-C 可用于主板供电、连接和排障；
- 如果 AAA 供电时慢速绿闪、USB 供电时恢复常绿，应优先检查电池电量、电池正负极、插头和开关接触，而不是立刻降级或刷写固件。

### 2.2 小车

- 使用小车自己的 7.4V 锂电池；
- 不要使用 AAA 电池盒驱动小车；
- 板子亮灯并不代表电池一定能提供足够的电机电流。

## 3. CyberBrick App 配置流程

### 3.1 添加设备

打开 CyberBrick App，进入 **我的设备 → 添加设备**，分别连接：

1. 发射端 `…8278`；
2. 接收端 `…3634`。

连接过程中如要求设置 PIN：

- PIN 必须完整输入 4 位数字；
- 未输入完整时，“确认”按钮为灰色；
- PIN 用于以后连接设备，应妥善记住。

### 3.2 导入项目

进入 **我的项目 → 导入项目 → 从本地导入**，选择 `BumperCar 360 woB.json`。

项目包含两个部分：

- `遥控器`：发射端输入和按键映射；
- `Bumper Car`：接收端的电机、舵机和控制逻辑。

### 3.3 上传到设备

打开 `BumperCar 360 woB`，点击右上角 **上传到设备**，按以下方式选择：

| 项目部分       | 对应设备                              |
| ---------- | --------------------------------- |
| 遥控器        | 发射端 `CyberBrick-[8278]` / `…8278` |
| Bumper Car | 接收端 `RC_MODULE` / `…3634`         |

上传时可能依次出现：

1. 固件升级；
2. 软件升级；
3. 上传配置并配对设备。

上传期间不要关闭软件、关闭设备、拔 USB 或断开小车电源。最终两台设备都应显示绿色“上传成功”。

## 4. 上电和首次测试

上传成功后：

1. 关闭遥控器和小车电源；
2. 先打开小车；
3. 再打开遥控器；
4. 等待约 5 秒建立通信；
5. 把小车架空，让轮子离地；
6. 测试前进、停止和转向；
7. 动作正确后再放到地面运行。

## 5. 指示灯判断

常见状态：

| 灯光 | 含义 |
| --- | --- |
| 绿灯常亮 | 已通电，但尚未建立无线连接 |
| 蓝灯常亮 | 蓝牙已连接 |
| 黄灯常亮 | 2.4GHz 已配对 |
| 蓝黄交替 | 蓝牙和 2.4GHz 均已连接 |
| 绿灯快速闪烁（约 2Hz） | 正在更新配置 |
| 绿灯约 1Hz、持续约 5 秒 | 控制对象识别 |
| 白灯常亮 | 等待固件更新 |
| 白灯闪烁 | 正在更新固件 |
| 红灯常亮 | 固件更新异常 |

### 5.1 本次遇到的慢速绿闪

现象：遥控器使用电池供电时持续“亮 1 秒、灭 2 秒”，连接蓝牙超时；改用 USB 供电后绿灯常亮，并能重新连接。

判断与处理：

1. 该节奏不符合正常固件更新的白灯闪烁；
2. 也不符合配置更新时更快的 2Hz 绿闪；
3. 完全断电 30 秒；
4. 使用 USB-C 供电重新连接；
5. USB 下正常时，优先更换或充足遥控器电池并检查接触；
6. 不要在没有进一步证据时贸然降级固件。

## 6. 蓝牙连接超时排查

按以下顺序处理：

1. 完全退出 CyberBrick App；
2. 关闭设备并彻底断电 30 秒；
3. 只打开当前要连接的一块板；
4. 使用稳定的 USB-C 供电重试；
5. 必要时在 Windows 蓝牙设备列表中忘记旧的 `RC_MODULE`，然后重新添加；
6. 如果设备依然无法启动或出现固件错误灯，再考虑官方恢复工具。

本次遥控器升级后仍能恢复连接并成功上传配置，因此没有证据表明此前进行了错误固件升级。

## 7. 当前项目的操控逻辑

从 `BumperCar 360 woB.json` 中确认：

- 左摇杆 Y 轴控制接收端 `MOTOR2`，即小车驱动电机；
- 右摇杆 X 轴控制 `PWM1`，即转向；
- 三挡开关触发 35、49、71 三个前进速率配置；
- 按键包含 `Boost` 和复位偏置逻辑；
- 当前驱动电机范围为 `min_value: 0`、`max_value: 50`。

因此当前版本的实际行为是：

- 左摇杆向前：前进；
- 左摇杆回中：停止；
- 左摇杆向后：仍然停止，不会倒车；
- 单独操作右摇杆只改变转向方向，不会让小车自行前进；
- 转弯需要同时给前进量和左右转向量。

“只能向前”和“单独按转向时不走”属于这份配置的设计结果，不是遥控器硬件故障。

## 8. 如果需要增加倒车

当前 `MOTOR2` 的速度下限为 0，因此无法输出反向速度。若要让左摇杆支持前进和后退，需要将驱动电机范围从：

```text
0 ～ 50
```

修改为类似：

```text
-50 ～ 50
```

修改后要再次完整上传到两台设备：

- 遥控器端需要新的摇杆映射；
- 小车端需要新的电机输出范围。

首次测试倒车时必须把小车架空，并确认电机、齿轮和轮胎的方向正确。如果实际正反方向与摇杆相反，应调整电机方向配置或电机接线，不要带负载反复试错。

## 9. 速度慢或转向发涩

依次检查：

1. 先把 7.4V 电池充满；
2. 分别测试遥控器三挡开关，确认是否处于低速档；
3. 架空小车，用手检查轮子是否顺滑；
4. 检查轮胎是否摩擦外壳；
5. 检查螺丝是否过紧；
6. 检查电线是否碰到旋转部件；
7. 确认两个驱动轮速度是否一致；
8. 同时给前进和转向输入，不要只拨转向摇杆判断车辆是否能走。

如果同时推前进和转向时仍突然停下，才需要进一步检查电池压降、机械卡滞、舵机供电或配置异常。

## 10. 7.4V 电池充电

套件电池通常为 `14500 7.4V 800mAh Li-ion Battery`，应使用套件专用的 **7.4V Lithium Battery Charger**，型号通常为 `B-XB003`，带匹配的 XH2.54 接口。

充电步骤：

1. 关闭小车；
2. 把电池从小车接收端断开；
3. 将电池插入专用 7.4V 充电线，核对方向，不要硬插；
4. 将充电器 USB 端插入电脑 USB 口，或普通 5V、1–2A 电源；
5. 在干燥、通风、远离可燃物的位置充电；
6. 全程有人看管；
7. 充满后先拔 USB，再断开电池。

禁止事项：

- 不要通过小车主板 USB-C 给这块电池充电；
- 不要使用普通 USB 线直接连接电池；
- 不要使用手机快充、9V 或 12V 充电模式；
- 不要覆盖充电器或电池；
- 电池发热异常、鼓包、变形、异味或冒烟时，应立即停止充电并移至安全区域。

## 11. 关键安全原则

- 电机测试前先把小车架空；
- 固件和配置上传时保持稳定供电；
- 不确定插头方向时不要用力；
- 不将 AAA 电池盒用于小车驱动；
- 不在无人看管时给锂电池充电；
- 没有明确故障证据时不要随意刷写、降级或使用第三方固件。

## 13. 线下碰碰车体验项目方案

> 方案讨论日期：2026-10-04。  
> 项目方向：不再采用复杂竞速跑道，回归 CyberBrick Duel Bumper Car 的核心玩法——撞击对方车辆并弹起驾驶员。

### 13.1 核心玩法

- 两辆车分别进入场地；
- 撞击对方车辆侧面，使对方驾驶员弹起；
- 驾驶员先被撞飞的一方落败；
- 单场可采用一局定胜负；
- 正式挑战可采用三局两胜；
- 避免使用车道狭窄、连续急弯的迷宫式地图。

### 13.2 收费方案

| 套餐 | 价格 | 定位 |
| --- | ---: | --- |
| 单局体验 | 9.9 元 | 降低首次体验门槛 |
| 三局挑战 | 19.9 元 | 主推套餐，适合冲击排行榜 |

展示价格时，`9.9 元/1局` 与 `19.9 元/3局` 应使用最大字号，确保路人能够快速理解。

### 13.3 场地地垫

当前候选为马里奥主题地垫：

- 图案：`MP-经典马里奥-1`；
- 推荐尺寸：`140 × 200cm`，在便携性和两车对战空间之间较均衡；
- `120 × 160cm` 为最低可用尺寸，便携但追逐和转向空间偏小；
- `160 × 230cm` 对战体验更好，但携带和铺设更麻烦；
- 购买前确认底面防滑，表面为短绒或平整材质，转弯时不易起皱、移位。

马里奥-1 的红蓝分区可以作为双方出生区，中间绿色区域作为交战区。

### 13.4 排行榜机制

榜单名称：`今日机器人战神榜`。

排名建议：

1. 按当天累计胜场排序；
2. 胜场相同时，胜率高者在前；
3. 胜率仍相同时，先达到该胜场者在前；
4. 每日闭店后结算，次日重新开始。

展示内容：

```text
机器人碰碰挑战赛

9.9元 1局
19.9元 3局

今日战神榜
第一名：________  ____胜
第二名：________  ____胜
第三名：________  ____胜
```

可选奖励：

- 第一名：免费挑战 3 局或小奖品；
- 第二名：免费挑战 1 局；
- 第三名：下次三局立减 5 元。

### 13.5 便携排行榜展示牌

当前看中的商品为桌面可擦写小黑板，最终推荐规格：

- 大号：`220 × 327mm`；
- 黑色可擦写板面；
- 胡桃木色支架；
- 数量 1 个；
- 若商品提供定制印刷，可优先选择定制款；
- 小号 `115 × 178mm` 过小，不适合展示价格与前三名。

大号尺寸接近 A4 加长版，适合桌面陈列和随身携带。版面空间有限，应突出价格和前三名，不要堆放完整规则。

### 13.6 已排除方案

- `120 × 180cm、车道宽24cm` 的灰色迷宫跑道：车道窄、连续急弯多，不适合首次遥控；
- 彩色椭圆跑道：适合入门，但作为竞速项目挑战性不足；
- `彩红跑道3`：实际为彩虹装饰贴，不是跑道；
- 亚博 `200 × 150cm` PVC 自动驾驶地图：车道约14cm，不适合 CyberBrick；
- 散装泡沫浮力棒边界：没有固定底座，受撞击后容易移动；
- 木质画架与大型落地白板：体积和重量不适合移动摆摊；
- 复杂定制竞速地图：暂时放弃，优先验证碰碰车玩法的客流和付费意愿。
